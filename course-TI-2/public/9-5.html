9.5 Boolesche Erfüllbarkeit (SAT)

Sei $V$ eine Menge von Booleschen Variablen. Ein Literal ist entweder eine Variable $x \in V$ (ein positives Literal) oder ihre Negation $\bar{x}$ (ein negatives Literal). Eine Klausel ist ein Oder von Literalen, also zum Beispiel $(x \vee \bar{y} \vee z)$. Eine CNF-Formel oder einfach CNF ist ein Und von Klauseln, also $C_1 \wedge C_2 \wedge \dots \wedge C_m$, zum Beispiel

$$ \begin{align} \label{eq-formula} (x \vee \bar{y} \vee z) \wedge (\bar{x} \vee y) \wedge (x \vee y \vee u) \wedge (\bar{x} \vee \bar{y}) \wedge (\bar{u} \vee \bar{z}) \end{align} $$

Eine Belegung weist jeder Variable einen Wahrheitswert False/True bzw. 0/1 zu. Formal ist eine Belegung also eine Funktion $\alpha : V \rightarrow \{0,1\}$ oder kurz $\alpha \in \cube^V$. Eine CNF-Formel $F$ über den Variablen $V$ (oder generell eine Boolesche Formel; oder noch allgemeiner: ein Schaltkreis) repräsentiert eine Boolesche Funktion $\cube^V \rightarrow \cube$; sie wird unter einer Belegung $\alpha$ also entweder falsch oder wahr. Wenn nun $F(\alpha)=1$ ist, dann sagen wir, dass die Belegung $\alpha$ die Formel $F$ erfüllt. Sie ist somit eine erfüllende Belegung und $F$ ist erfüllbar. Bei CNF-Formeln ist das konzeptuell ganz einfach:

  • $\alpha$ erfüllt das positive Literal $x$ wenn $\alpha(x)=1$ ist.

  • $\alpha$ erfüllt das negative Literal $\bar{x}$ wenn $\alpha(x)=0$ ist.

  • $\alpha$ erfüllt die Klausel $C$ wenn $\alpha$ mindestens ein Literal in $C$ erfüllt.

  • $\alpha$ erfüllt die Formel $F$ wenn $\alpha$ jede Klausel in $F$ erfüllt.

Zum Beispiel erfüllt die Belegung $\alpha = [u \mapsto 0, x \mapsto 0, y \mapsto 1, z \mapsto 1]$ die obige Formel (\ref{eq-formula}); die Belegung $\beta = [u \mapsto 1, x \mapsto 0, y \mapsto 0, z \mapsto 1]$ erfüllt $F$ nicht. Wenn es für $F$ mindestens eine erfüllende Belegung gibt, so nennen wir $F$ erfüllbar, ansonsten unerfüllbar. Die Formel in (\ref{eq-formula}) ist erfüllbar

Eine CNF-Formel heißt $k$-CNF wenn jede ihrer Klausel maximal $k$ Literale enthält. Die Formel in (\ref{eq-formula}) ist eine 3-CNF (und nach unserer Definition auch eine $4$-CNF und auch eine $5$-CNF; und natürlich ist die Formel in (\ref{eq-formula}) auch ein Schaltkreis, wenn auch nicht mit Fan-in 2).

Problem 9.5.1 Gegeben eine 3-CNF-Formel $F$, entscheide, ob $F$ erfüllbar ist oder nicht.

Wie finden wir eine erfüllende Belegung? Ähnlich wie im letzten Kapitel für $k$-Colorability. Wir haben eine partielle Belegung, also eine Funktion $\alpha_i : \{v_1, \dots, v_i\} \rightarrow \cube$.

  • Wenn eine Klausel von $F$ unter $\alpha_i$ bereits False wird, gibt False zurück.

  • Setze $x_i$ probeweise auf True: $\alpha_{i+1} := \alpha_i \cup [x_i \mapsto 1]$. Teste rekursiv, ob sich $\alpha_{i+1}$ zu einer erfüllenden Belegung erweitern lässt.

  • Setze $x_i$ probeweise auf False: $\alpha_{i+1} := \alpha_i \cup [x_i \mapsto 0]$. Teste rekursiv, ob sich $\alpha_{i+1}$ zu einer erfüllenden Belegung erweitern lässt.

  • Falls einer der beiden Zweige erfolgreich war, gib die gefundene erfüllende Belegung zurück. Ansonsten melde, dass $F$ unerfüllbar ist.

Implementierung in Python

In meiner Python-Implementierung kann alles eine Variable sein, was man als Schlüssel in einem Dictionary verwenden kann, also Int, Character, String, Tupel etc. aber keine Listen. Wenn nun x eine Variable ist, dann sind (x, True) und (x, False) die Literale $x$ und $\bar{x}$. Ich unterscheide also zwischen der Variable $x$ und dem positiven Literal $x$. Eine Klausel ist nun einfach eine Liste von Literalen, und eine Formel ist eine Liste von Klauseln. 

[x, y] = ['x', 'y']
formula_2 = [ [(x, True), (y, True)], [(x, True), (y, False)], [(x, False)] ]

Der Code erzeugt einen Rekursionsbaum der Tiefe maximal $n = |V|$, in dem jeder innere Knoten zwei Kinder hat (einen für $v \mapsto 1$ und einen für $v \mapsto 0$). Jeder Aufruf selbst hat Laufzeit $\poly(n)$, je nachdem, wie man is_clause_alive und die partielle Belegung alpha implementiert. Die Laufzeit ist somit höchstens $O(2^n \poly(n))$.

Übungsaufgabe 9.5.3 Rufen Sie meinen DPLL-Illustrator auf und spielen Sie damit rum. Denken Sie sich interessante unerfüllbare CNF-Formeln aus.

Wir beobachten ein ähnliches Phänomen wie bei Graphenfärbbarkeit: eine Lösung zu finden scheint nicht ganz einfach zu sein; wenn uns jemand aber einen Lösungsvorschlag unterbreitet, also eine Belegung $\alpha$ gibt, so können wir natürlich effizient überprüfen, ob $\alpha$ die Formel $F$ erfüllt oder nicht. 

def is_formula_satisfied(variables, clauses, alpha):

    def is_literal_satisfied(lit):
        (x, b) = lit 
        if x not in alpha: 
            return False 
        return alpha[x] == b 
    
    def is_clause_satisfied(clause):
        return any(is_literal_satisfied(lit) for lit in clause)
    
    formula_satisfied = all(is_clause_satisfied(clause) for clause in clauses)
    return formula_satisfied


[u, x, y, z] = ['u', 'x', 'y', 'z']
variables = [u,x,y,z]
C1 = [(x, True), (y, False), (z, True)]
C2 = [(x, False), (y, True)]
C3 = [(x, True), (y, True), (u, True)]
C4 = [(x, False), (y, False)]
C5 = [(u, False), (z, False)]

formula = [C1, C2, C3, C4, C5]

assignment_1 = {u : 0, x : 0, y: 1, z : 1 }
print(is_formula_satisfied(variables, formula, assignment_1))

assignment_2 = {u : 1, x : 0, y: 0, z : 1 }
print(is_formula_satisfied(variables, formula, assignment_2))

Der Algorithmus is_alpha_satisfying_assignment ist eine Zertifikatmaschine: sie erwartet auf dem Eingabeband eine CNF-Formel und auf dem Zertifikatband eine Belegung $\alpha$. Falls nun $F$ erfüllbar ist, dann gibt es eine Belegung $\alpha$, so dass is_alpha_satisfying_assignment$(F,\alpha)$ akzeptiert bzw. True zurückgibt. Ist im Gegenteil $F$ unerfüllbar, so wird sie immer ablehnen, egal welches $\alpha$ man ihr auf das Zertifikatband schreibt. Daher:

Beobachtung 9.5.2 SAT ist in NP.
